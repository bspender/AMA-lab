### Facilitator Artifact Inventory

Derive every effort label from this itemized inventory. Do not assert a label. Artifact page count, input word count, and brief length are not valid proxies; cost concentrates in calibration and the answer key.

| # | Inventory item | What to record |
|---|---|---|
| 1 | Participant input files | Count and approximate length |
| 2 | Seeded defects or planted material | Count, and whether each maps to a discoverable rule |
| 3 | Facilitator answer key | Reference converged artifact, defect-to-rule mapping, pass-1 versus pass-N exemplars |
| 4 | Calibration runs | Pilot executions needed so the loop neither collapses in one pass nor fails to converge |
| 5 | Diagnostic guide | Stuck-versus-slow signals and the hint ladder |
| 6 | Variant cost | Work to produce one additional cohort or domain variant |
