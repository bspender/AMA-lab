# AMA Loop-Engineering Workshop Idea Ledger

This file is the durable idea registry for workshop use-case ideation. Read it before generating candidates and update it after every execution iteration.

## Rules

- Stable IDs use kebab-case and are never reassigned.
- A renamed or reframed idea keeps its original ID when the CSA job, trigger, loop transformation, and output artifact are materially the same.
- A ledgered idea is not eligible as a new idea.
- `REVISIT: <idea-id>` requires a new testable hypothesis and retains the original ID.
- Record every genuinely new idea seen, including ideas rejected before scoring.

## Registry states

| State | Meaning |
|---|---|
| `seen` | Generated previously; not eligible as new |
| `evaluated` | Gated or scored previously |
| `selected` | Included in a prior Top 10 |
| `workshopped` | Used in an actual workshop |
| `retired` | Intentionally excluded from future consideration |
| `revisit-eligible` | May be reevaluated with an explicit new hypothesis |
